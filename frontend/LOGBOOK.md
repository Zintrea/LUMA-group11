📂 1. การเตรียมโครงสร้างโปรเจกต์ (Setup)
เริ่มจากการสร้างพื้นที่ทำงานให้เป็นระเบียบ เพื่อแยกระบบหน้าตาเว็บและระบบสั่งการออกจากกัน:

สร้างโฟลเดอร์หลักชื่อ luma_frontend และสร้างไฟล์ index.html กับ README.md ไว้ด้านในสุด

สร้างโฟลเดอร์ชื่อ css และสร้างไฟล์ style.css ไว้ข้างในสำหรับตกแต่งความสวยงาม

สร้างโฟลเดอร์ชื่อ js และสร้างไฟล์ script.js ไว้ข้างในสำหรับเขียนลอจิกสั่งการ

🏗️ 2. การสร้างหน้าตาเว็บ (HTML & CSS)
ขั้นตอนนี้คือการสร้าง "โครงกระดูก" ให้หน้าเว็บ โดยเราใช้เครื่องมือชื่อ Bootstrap เข้ามาช่วยจัด Layout ให้ใช้งานง่าย:

เปิดไฟล์ index.html แล้วนำโค้ดโครงสร้างไปวาง โค้ดส่วนนี้จะแบ่งหน้าจอเป็นสองฝั่งคือ แผงควบคุม (ซ้าย) และพื้นที่แสดงรูป (ขวา)

บรรทัดล่างสุดของไฟล์นี้จะมีการฝังคำสั่ง <script src="js/script.js"></script> เอาไว้ เพื่อให้หน้าเว็บเรียกใช้ระบบสมองที่เราจะเขียนในขั้นตอนต่อไป

🧠 3. การใส่ระบบสั่งการ (JavaScript)
เว็บที่มีแค่โครงสร้างจะยังกดปุ่มไม่ได้ เราต้องใส่ "ลอจิก" ให้มันทำงานและคุยกับระบบหลังบ้านได้:

เปิดไฟล์ js/script.js แล้วนำโค้ดไปวาง โดยบรรทัดแรกสุดคือ BACKEND_URL ซึ่งทำหน้าที่เป็นตัวกำหนดว่าจะยิงข้อความไปหาเซิร์ฟเวอร์ที่ไหน

เมื่อผู้ใช้กดปุ่ม Generate โค้ดจะทำการล็อกปุ่ม โชว์ไอคอนโหลด แล้วยิงข้อมูลคำสั่ง (Prompt) ไปที่ Backend ทันที

เมื่อ Backend ประมวลผลเสร็จและส่งรหัสรูปภาพ (Base64) กลับมา สคริปต์ตัวนี้จะนำรหัสไปแปลงและแสดงผลเป็นรูปบนหน้าเว็บ

🚀 4. การรันระบบและการอัปโหลดงาน
ขั้นตอนสุดท้ายคือการทดสอบว่าสิ่งที่ประกอบมาทำงานได้จริง และบันทึกเข้าสู่ระบบควบคุมเวอร์ชัน (Git):

เปิดโปรแกรม Terminal นำทางเข้าไปที่โฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง python -m http.server 8080 เพื่อจำลองเปิดเซิร์ฟเวอร์

ทดสอบเปิดเบราว์เซอร์ไปที่ http://localhost:8080 หากทุกอย่างถูกต้อง หน้าเว็บจะพร้อมให้ทดลองกรอกข้อความ

คัดลอกคู่มือการใช้งานไปใส่ใน README.md จากนั้นเซฟงานทั้งหมดด้วยคำสั่ง git add . และ git commit เพื่อส่งงานขึ้นระบบส่วนกลาง
