# Frontend

ส่วนนี้เป็นงานของผู้รับผิดชอบ Frontend

README นี้เป็นตัวอย่างสำหรับบันทึกวิธีใช้งานของส่วนนี้
ให้แก้ข้อมูลให้ตรงกับงานจริงเมื่อเริ่มพัฒนา

## 1. ส่วนนี้ทำอะไร

ตัวอย่าง:

แสดงหน้าเว็บสำหรับให้ผู้ใช้ใช้งาน LUMA เช่น
- กรอก Prompt
- กด Generate
- แสดงรูปผลลัพธ์

## 2. ต้องลงอะไร

ตัวอย่าง:

- Web Browser
- HTML
- CSS
- JavaScript

ถ้ามี Library หรือโปรแกรมเพิ่มเติม ให้ระบุไว้ตรงนี้

## 3. ติดตั้งและเปิดยังไง

ตัวอย่าง:

ถ้าเป็น HTML ธรรมดา:

เปิดไฟล์:

```text
index.html
```

หรือถ้าใช้ Local Server ให้เขียนคำสั่งจริงไว้ตรงนี้ เช่น:

```bash
python -m http.server 8080
```

แล้วเปิด:

```text
localhost
```

## 4. ทดสอบยังไง

ตัวอย่าง:

1. เปิดหน้าเว็บ
2. หน้าเว็บต้องแสดงผลได้
3. ช่อง Prompt ต้องใช้งานได้
4. ปุ่ม Generate ต้องกดได้

ถ้าทำได้ ถือว่าส่วน Frontend พร้อมสำหรับนำไปเชื่อมกับ Backend
