🌟 LUMA - AI Image Generation Platform

แพลตฟอร์มสำหรับสร้างรูปภาพด้วย AI จากข้อความ (Text-to-Image) พร้อมเครื่องมือแต่งรูปอัจฉริยะและระบบจัดการหลังบ้าน (Admin Panel)

💻 สิ่งที่ต้องเตรียม (Prerequisites) ก่อนเริ่มรันโปรเจกต์

สำหรับฝั่ง Frontend เราได้รวมโปรแกรม Nginx (แบบพกพาสำหรับ Windows) ไว้ในโฟลเดอร์โปรเจกต์แล้ว คุณจึง ไม่ต้องติดตั้งโปรแกรมเซิร์ฟเวอร์อะไรเพิ่มเติม สิ่งที่ต้องมีในเครื่องคือ:

Web Browser: แนะนำ Google Chrome หรือ Microsoft Edge (อัปเดตล่าสุด)

Text Editor (สำหรับคนแก้โค้ด): แนะนำ VS Code

Git: สำหรับดึงโค้ดล่าสุด (git pull)

🚀 ขั้นตอนการเปิดรันระบบ (สำหรับเพื่อนร่วมทีม)

เพื่อให้หน้าเว็บ (Frontend) สามารถเชื่อมต่อกับ AI และฐานข้อมูลได้สมบูรณ์ กรุณารันระบบตามลำดับ 1 -> 2 -> 3 ดังนี้ครับ:

ขั้นที่ 1: เตรียมฐานข้อมูล (Database)

เปิด Terminal และรันคำสั่ง Docker เพื่อเปิดใช้งาน PostgreSQL:

docker start luma-test-db


(หมายเหตุ: หากเพิ่งดึงโปรเจกต์มาครั้งแรก ให้ทำตามขั้นตอน Setup Database ในกลุ่มก่อน)

ขั้นที่ 2: รันระบบหลังบ้าน (Backend - Flask)

เปิด Terminal หน้าต่างใหม่ แล้วเข้าไปรัน Backend:

cd backend
pip install -r requirements.txt
python app.py


(ปล่อยหน้าจอนี้รันค้างไว้ ห้ามปิด Terminal)

ขั้นที่ 3: 🎨 รันระบบหน้าบ้าน (Frontend & Nginx) [ส่วนสำคัญ]

โปรเจกต์นี้ใช้ Nginx เป็นตัวจำลอง Web Server และ Reverse Proxy (เชื่อมต่อพอร์ตหน้าบ้านกับหลังบ้านเข้าด้วยกัน)

วิธีรัน Frontend:

เปิด Terminal ใหม่ แล้ว cd เข้ามาที่ โฟลเดอร์หลักของโปรเจกต์ (โฟลเดอร์ที่มีไฟล์ nginx.exe วางอยู่)

สั่งรัน Nginx ตามโปรแกรมที่คุณเปิดใช้งานอยู่:

👉 ถ้าใช้ Command Prompt (CMD):

start nginx


👉 ถ้าใช้ PowerShell หรือ Terminal ใน VS Code:

.\nginx.exe


(เมื่อรันคำสั่งแล้ว หน้าต่างจะกระพริบ 1 ครั้ง ถือว่า Nginx ทำงานอยู่เบื้องหลังแล้ว)

🔗 วิธีการเข้าดูเว็บไซต์และการส่งลิงก์ (Sharing the Link)

เมื่อรันครบทั้ง 3 ขั้นตอนแล้ว คุณสามารถเปิดดูเว็บหรือส่งลิงก์ให้เพื่อนเทสต์ได้ 2 รูปแบบครับ:

1. ดูบนเครื่องของตัวเอง (Localhost):
เปิด Web Browser แล้วพิมพ์ URL ลิงก์ใดลิงก์หนึ่งต่อไปนี้:

http://localhost

http://127.0.0.1

2. ส่งลิงก์ให้เพื่อน/อาจารย์เปิดดูผ่านมือถือ (ต้องต่อ Wi-Fi วงเดียวกัน):
หากต้องการให้คนอื่นเปิดเว็บจากมือถือหรือคอมพิวเตอร์เครื่องอื่นที่เชื่อมต่อ Wi-Fi/LAN เดียวกันกับคุณ ให้ทำดังนี้:

เปิด Command Prompt แล้วพิมพ์คำสั่ง ipconfig

มองหาบรรทัดที่เขียนว่า IPv4 Address (เช่น 192.168.1.45)

ส่งลิงก์นี้ให้เพื่อน: นำเลขนั้นมาสร้างเป็นลิงก์ เช่น http://192.168.1.45
(เพื่อนจะสามารถใช้งานเว็บและกดเจนรูปได้เหมือนรันบนเครื่องตัวเอง)

🔄 วิธีแก้โค้ด Frontend และดูผลลัพธ์ (สำหรับ Developer)

หากคุณแก้ไขไฟล์ฝั่ง Frontend (เช่น index.html, script.js, style.css) หรือมีการตั้งค่า Nginx ใหม่:

แก้แค่ HTML/CSS/JS: สามารถกดปุ่ม F5 หรือรีเฟรชหน้าเบราว์เซอร์เพื่อดูผลลัพธ์ใหม่ได้ทันที!

แก้ไฟล์ตั้งค่า Nginx (nginx.conf): ต้องสั่งให้ Nginx โหลดค่าใหม่ โดยเปิด Terminal (ที่โฟลเดอร์หลัก) แล้วพิมพ์:

nginx -s reload


🛑 วิธีปิดระบบ (เมื่อเลิกใช้งาน)

เนื่องจาก Nginx ทำงานอยู่เบื้องหลัง (Background Process) เมื่อทำงานเสร็จแล้ว ต้องสั่งปิดเสมอ:

ปิด Frontend (Nginx): รันคำสั่งนี้เพื่อบังคับปิดการทำงานของ Nginx:

taskkill /f /im nginx.exe


(หรือใช้คำสั่ง nginx -s quit ก็ได้เช่นกัน)

ปิด Backend (Flask): ไปที่หน้าต่าง Terminal ของ Python แล้วกดปุ่ม Ctrl + C

ปิด Database: docker stop luma-test-db

👑 วิธีการตั้งสิทธิ์ Admin (สำหรับผู้ดูแลระบบ)

บัญชีที่สมัครสมาชิกใหม่ผ่านหน้าเว็บเริ่มต้นจะเป็นสิทธิ์ user หากต้องการเข้าหน้า Admin Panel ให้รันคำสั่งนี้ผ่าน Terminal เพื่อเปลี่ยนสิทธิ์ตัวเองใน Database:

docker exec -i luma-test-db psql -U postgres -d luma_db -c "UPDATE users SET role = 'admin' WHERE username = 'ชื่อผู้ใช้ของคุณ';"


(เปลี่ยนคำว่า 'ชื่อผู้ใช้ของคุณ' เป็น Username ที่คุณสมัครไว้ แล้วทำการ Log out และ Log in ใหม่)
